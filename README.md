# SinjidRemake

Remake of the original flash game Sinjid: Shadow of the Warrior (https://armorgames.com/play/316/sinjid-shadow-of-the-warrior)

# Description

​Unity based remake of the original Armor Games flash game Sinjid Shadow of the warrior, an adventure rpg with turn based battles.  Fan project to make it available on multiple platforms and with controller support. Kept the original assets but re-balanced a bit and introduced a few secrets and additional content.



Controls:

WASD - Move

Space - Talk

Mouse - UI control



Or with game pad:

Left stick - Move

Cross/A - Talk/Click in UI

Circle/B - Exit in UI

Square/X - Health Potion

Triangle/Y - Mana Potion

Start/Menu - Open Inventory screen

L1/R1/LB/RB - Switch between Skills and Inventory screen
